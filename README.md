## 🚀 What is this?

**Ceylon NIC Engine** is a web app that lets you generate **fake but realistic** Sri Lankan National ID Cards (NICs) for fun, learning, and testing.

It combines:
- 🎲 Random Sinhala names
- 📍 Smart addresses
- 🧠 Gemini AI-powered portraits
- 📇 PDF417 barcodes

With a modern UI and super chill vibes 🌈

---

## 🧰 Features

- 🆔 Generates NICs that *look* real (but aren't!)
- 👦 Sinhala name/person generation (Tamil & Muslim coming soon)
- 🏡 Address & location data included
- 📸 Portraits made by Gemini AI
- 📇 PDF417 barcode **matches the NIC data**
- 🌗 Beautiful dark-orange UI (TailwindCSS)
- ⚙️ Built with Flask (soon Gunicorn)

## 🧠 AI + Barcode Sync

📇 **Barcode = Truth.**  
The PDF417 barcode is encoded with **the same exact data** as shown on the NIC:
- Full Name (Sinhala/Tamil/English)
- DOB
- Gender
- Province
- NIC Number

<p align="center">
  <img src="https://raw.githubusercontent.com/ChocoJaYY/Ceylon-NIC-Engine/refs/heads/main/img/barcode.png" alt="Barcode Demo preview"/>
</p>

> 📌 The PDF417 barcode is 100% encoded with the exact generated data for the fake identity.  
> If someone scans the barcode, the data on the front side of the ID card will match the decoded barcode content **exactly**.
